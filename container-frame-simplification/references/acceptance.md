# 结果核验与回归

1. 先冻结原始输入配置、SHA-256、工况、批准与独立参考。匿名包保留形状、位姿、中性层级和允许量测，运行进程仅读脱敏包及提示词。原名和正确答案另存于工程侧。
2. 测试换名、重名、重编号、模型旋转平移后的角色一致性。逐类核对角柱两端、活动梁夹持、容易误留的跨接板和附件配对。移除一端、侧母件、配对反证或工况许可后，对应动作应收缩为待复核。几何模型少一件或隐藏分支不应自动生成工程清理决定。
3. 对 X_T 验收，核对实际清理实体的几何差集和全部留件的一一配对。已有保护清单时逐体核对。重复同形同位实例按实体重数验证，候选身份不唯一时暂留。
4. B 下舱验收使用批准前三组的历史 X_T 为输入、批准后的历史回读为独立参考。验证 10 块底架垫板、22 块顶盖连接板和 22 个下方固定座的精确几何差集，并核对 664 个活动梁连接。复盘案例另含 160 个早期活动梁误删、Q3 跨接薄板误留和 112 个历史绑线扣的版本对账。样本输入、参考和回执均存项目目录，以路径及指纹报告。

全流程按几何识别、接触落实和力学验证分别验收。跨箱型准确率由未参与标定的不同结构箱体独立衡量，分开统计承力件误删、附件误留、错配接口和拒判。包内快速回归覆盖唯一对应、重合拒删、保护与重数，项目完整验收需另跑实际 CAD。
