# 框架角色识别与去留

## 工程处置

| 对象 | 默认处置 | 工程核查 |
|---|---|---|
| 一级主框、二三级梁系及实际节点 | 保留几何 | 保留角件、角柱、侧梁、横纵梁、斜梁、叉槽、端板等需要的主路径。 |
| 四级底板 | 保留几何 | 核对承压工作面和项目要求保留的底蒙板。 |
| 四级其他板件 | 清理候选 | 仅围护或封闭用途时清理。节点加强、焊成有效截面和真实跨结构传力按实际角色复核。 |
| 开闭件、运动附件、设备及安装件 | 清理候选 | 核对唯一母件、工况接口和要保留的孔面。 |
| 活动梁端板、紧固件和母件 | 保留几何 | 按两侧母件、孔轴和承压层序确认；等效连接参数和试验修正系数按工况留待工程确定。 |

按项目工况逐项核对角件、底板承压面、底角件支承限位、吊孔和夹紧面。结合上下或两侧母件追溯结构路径。CAD 配合、邻近、几何贴合、工程确认焊接和仿真连接分别记录。实际预留焊缝保留两侧有效面，以工况确认的方式在前处理中建接触。

## 可复核的识别证据

| 角色或场景 | 形状与位置 | 连接验证及拒判 |
|---|---|---|
| 角件、角柱和门锁杆 | 角位、长细比、高度、截面、孔方向 | 柱两端对应同一角位的上下角件；杆检查同一门扇的两个导向座与轴线。缺关键端证或有配对竞争时待判。 |
| 活动梁夹持组 | 螺杆、圆孔或长圆孔、厚度和梁端 | 两板贯通、两独立母梁、螺栓头到螺母的承压链。缺一侧或分段承压证据时保护至工程复核。 |
| 跨接薄板和封板 | 构成截面、板宽及端部朝向 | 端部贴合仅作证据。以确切焊接、夹持或工况接口决定是否参与结构。 |
| 围护件、设备及钢网 | 大薄弯面、外壳子件、规则网丝等 | 看端部、共同面、包装和局部母件。合并实体且分界不清时标注局部分割区域。 |
| 侧门铰链座、绑线扣和绳环 | 双耳孔、带孔薄带、带脚弯环等 | 核对转轴或局部安装脚，辨别端门和侧门、单母件和跨接。 |
| 垫板、固定角钢及加强片 | 底侧梁下薄板或外侧角形组合 | 检查接触面、同高支承、底蒙板接口和夹紧用途。局部安装组按整组复核。 |
| 顶盖连接板和下方固定座 | 顶部折弯槽孔板与下方倒 U 形孔件 | 上件薄顶盖、槽孔对轴、双向唯一配对、下件只贴合一根框架梁。范围确认后清理。 |

箱体尺寸、轴向和间隙由模型量测。原案例的 1 mm、3 mm 等读数随验收证据引用。换箱型时先检查筛选范围、几何差异及当前工况。每项记角色、建议动作、采用决定和验证状态。原名回查和工程期望只在封存后对账。疑点保留并用整体与局部图说明。
